TraceEagle（中文界面亦称“老鹰抓包”）是一款集成了网卡原始抓包与代理解密能力的跨平台工具，其核心优势在于开箱即用，无需繁琐的证书配置即可自动解密 HTTPS 流量。以下是基于官方文档整理的使用教程。

一、安装与初始化
首先访问官网下载对应系统的桌面客户端（支持 macOS、Windows、Linux）。手机流量（iOS/Android）也需通过连接电脑端的桌面应用来抓取。

Windows：运行安装包即可，网卡抓包所需的 Npcap 驱动会在需要时自动安装。

macOS：由于应用尚未通过 Apple 公证，首次打开若被拦截，需前往“系统设置 → 隐私与安全性”中点击“仍要打开”以授权。

权限请求：首次使用“网卡抓包”或“系统级抓包”时，应用会请求管理员权限，点击同意即可；若仅使用“指定程序抓包”或“代理抓包”，通常无需此步骤。

二、最快上手：指定程序抓包
对于新手，建议先使用“指定程序抓包”来体验明文解密效果，此方式无需配置系统代理，也无需安装证书。

在应用内选择“指定程序抓包”（或本机指定程序抓包）。

在列表中选择你的浏览器（或手动输入启动命令）。

点击“开始”，TraceEagle 会自动拉起一个受控的浏览器窗口。

在该浏览器中访问任意 HTTPS 网站，返回应用界面，点击请求列表中的条目，即可直接查看解密后的请求头、Body 及响应明文。

三、按场景选择抓包模式
根据你的目标，参考下表切换模式：

抓取本机浏览器/程序（需改包重放）：选择代理抓包。这是最通用的模式，既能看明文也能拦截修改。

抓取整机流量（含不走代理的 App、UDP/QUIC、HTTP/3）：选择网卡抓包。它能捕获底层原始数据包，解决普通代理看不见的流量。

抓取 iOS/Android 手机：需先用数据线连接电脑。iOS 支持免越狱抓包；安卓高版本系统若不信任用户证书，可使用应用内置的特定方案。

四、进阶：处理 SSL Pinning 与改包
若目标 App 绑定了证书导致开启代理后断网，可在代理会话中选中该 App，使用解除证书绑定（去 Pin）功能。该操作仅让 App 信任代理证书，从而恢复联网并允许解密。注意，Android 设备通常需要 Root 权限，iOS 则可能需要重签名的 App。
此外，抓到的请求支持右键直接进行压力测试或会话重放，方便复现流程或验证接口性能。

五、常见问题排查
抓不到请求：若目标不走系统代理，请切换至“网卡抓包”。

看到全是密文：说明解密未生效，请检查证书安装状态（针对代理模式），或改用“指定程序抓包/应用层取明文”。

HTTP/3 缺失：HTTP/3 基于 UDP，普通代理无法捕获，需使用网卡抓包模式配合解密。
